# Mobile app QA — 26 October 2026

Tested the current workspace, preserving the edits that were already present. The website fixes were deployed and promoted on 26 October 2026 after staged verification.

## Fixes

1. **Forecast submit button clipped on small phones.** At a 320 × 640 viewport, the form had 258 px available but its implicit grid column measured 323 px. The submit button extended past the card. Constraining the grid track to `minmax(0,1fr)` keeps the button inside the form while retaining its 48 px target.
2. **Forecast prices split across lines.** The minimum 56 px price font split `2,649.55` into `2,649.5` and `5` on a narrow phone. A smaller responsive mobile size keeps the tested prices and currencies on one line. Final check: 35 px content height with a 35.2 px line height at 320 px.
3. **Stock deep links rejected ampersands.** Links for `M&M.NS` and `J&KBANK.NS` fell back to another instrument. The link validator now accepts the same symbol characters as the market API. Verified with regression tests and an M&M chart link on an isolated local origin.
4. **Shared watchlists rejected or lost ampersand stocks.** A list containing only these symbols threw during share-link creation; importing another list could also discard existing ampersand symbols. Updated sharing/import validation and added a round-trip/preservation regression. Verified preview → save both stocks → reopen sharing in the browser without a crash.
5. **Background-task timeout could disappear before completion.** The unreferenced timeout let a one-shot process exit before recording a timed-out task, cancelling six tests. Keep that timer alive while dispatch is pending and clear it in `finally`. The existing timeout test now passes, along with the full suite.

## Limits

These were responsive browser checks, not tests on a physical Android phone or Android emulator. A reduced viewport approximates available keyboard space but does not verify Android's actual keyboard or visual-viewport behavior. Android Chrome installation, native share-sheet completion, notification permission and closed-app push delivery remain unverified. No live broker orders or real signup submissions were made. Backup parsing and restoration are covered by automated tests; an end-to-end file-picker restore was not performed. Public information pages, the local registration viewer and the separate Jarvis dashboard were not part of the 13-screen browser sweep.
