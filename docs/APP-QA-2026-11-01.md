# Alpha Nova app QA and performance — 1 November 2026

## Fixed

- Simultaneous chart/quote requests now share the same upstream request when symbol, range, adjustment and daily-history settings match. Failed requests are removed so retries work.
- Quote loading uses four continuously occupied workers. One slow symbol no longer holds back the next group of healthy symbols.
- Quote batches return available coverage within a 24-second server budget, ahead of the browser's 30-second timeout. Missing symbols remain explicitly reported; late work cannot mutate returned results.
- Completely unavailable quote batches explicitly send `Cache-Control: no-store`.
- The full runtime stock directory refresh starts when search opens, instead of competing with initial workspace data. The measured public directory response was 222,429 decoded bytes.
- Generated stock data uses compact tuples with default sectors. All 3,242 records and the snapshot timestamp are preserved exactly, including company names, symbols and curated sectors. Future directory refreshes use the same generator.

## Validation

- Full JavaScript suite: **358 passed, zero failed** (352 existing tests plus six regression checks).
- NIFTY EDGE Python suite: **5 passed**, with the declared dependencies installed in a temporary Python 3.11 environment.
- Production build and whitespace checks passed.
- Three new quote checks were observed failing before the fixes: duplicate upstream calls, blocked quote workers and missing failure cache control. They pass after the fixes. Additional tests cover deadline/partial coverage, retry recovery and catalog serialization.
- Exact comparison confirmed that all 3,242 generated catalog objects equal the original snapshot.
- Live route smoke checks covered all 13 workspaces: Overview, Charts & plan, Forecast, Markets, Screener, Delivery radar, Futures & options, Institutional flows, News, Watchlist, Portfolio, Trade journal and Price alerts.
- Twelve public API checks returned HTTP 200: directory, screener, benchmark quotes, chart, adjusted daily forecast history, delivery, flows, deals, rotation, company news, options and signup status. These were spot checks, not a guarantee of upstream availability.
- Local browser interactions verified company search, saving a watchlist stock, chart navigation, creating/persisting/deleting/restoring an alert, and portfolio quantity/cost/P&L calculations. Disposable local holdings and alerts were removed afterward.
- Mobile navigation and route rendering checked at a 360-pixel viewport. The inspected routes had no document-level horizontal overflow. Forecast completed successfully. Live NIFTY EDGE rendered its closed-session research snapshot.

## Performance measurements

Same-machine production builds before/after:

| Main JavaScript | Before | After | Reduction |
| --- | ---: | ---: | ---: |
| Uncompressed | 569.51 KB | 483.92 KB | 15.0% |
| Gzip | 165.35 KB | 161.51 KB | 2.3% |

The 222 KB directory response is deferred until search opens. These byte reductions do not establish an equivalent improvement in page-load time or Core Web Vitals. Browser timing instrumentation was unavailable through the connected browser; no Lighthouse score or field speed claim is made.

## Limits

No real broker order, signup submission, notification opt-in or live personal-data mutation was performed. Phone checks covered layout and key interactions, not every control on every device. Data feeds were tested during a closed-market weekend; market-open behavior remains dependent on upstream providers. Existing unrelated workspace changes were retained.
